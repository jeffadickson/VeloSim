Historical Python prototype sources, preserved for comparison during the C# migration.
The active helpers are compiled C# under src/VeloSim.Core, src/VeloSim.Tools and tools/VeloSim.Build.
Use the root Makefile and Ninja build. These historical scripts are not supported build entry points; their original relative paths may no longer resolve. Git checkpoint075 preserves their original layout.
Upstream dependency generators remain under external/ and are controlled by those projects.
