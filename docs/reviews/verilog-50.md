# Fifty-iteration unsigned RTL review

These are independent AI peer reviews, not human approvals. Scope is the structural single-posedge-process backend and its same-source differential tests.

- Checkpoint 10 semantic review identified a signed-expression miscompile risk. The fix conservatively rejects signed operation trees and folded negative integer constants. Real rejection tests exposed missing UHDM signed flags; the corrected guard also recognizes actual typespecs, integer constant kind and signed literal metadata. The final rebuilt negative fixture rejects correctly.
- Checkpoint 20 tooling review identified a potential false pass when both traces derived their port shape from exported IR. The fixture now independently asserts every expected port name, direction, width and NBA writer before generating the reference testbench. Unsigned shift/reduction sizing was accepted; validation and emission both use the left operand width for shifts.
- Checkpoint 30 semantic review accepted unsigned multiplication/division/remainder, zero-divisor X results, conditional bit merging, context propagation and the direct native oracle tests. A stale exporter build was detected by the actual source test and rebuilt; all 24 new operators then matched Icarus in the initial width case.
- Checkpoint 40 tooling review accepted the independent interface checks, strict trace parsing, unchanged source/build/tool fingerprints, effective C++ compiler/Ninja identities, and full trace comparison. The eleven-width matrix must pass before qualification is claimed.
- Checkpoint 50 final reviews by both peers found no open blocker. They accepted the bounded unsigned scope, explicit serial execution and the operator-based FIFO's binary-control queue contract. Final committed-source coverage, native publication and packaged checks remain execution requirements; their results are delivered with the validation artifacts.
- The first full checkpoint-50 run passed 185 tests and failed the negative-parameter rejection. UHDM stored its parameter value only on a separate assignment node; copying the empty parameter value into a constant silently produced zero. A minimal reviewed guard now rejects unmaterialized parameter values before conversion. Targeted rejection and positive FIFO checks plus a fresh full coverage run are required after that repair; the failed run is retained with the delivered logs.

The exporter is exercised by actual positive/negative integration tests but is outside the default LLVM core/runtime coverage denominator. No claim is made about arbitrary signed expressions, hierarchy, general event scheduling or multi-process structural simulation. Worker settings 1/4/8 are repeat configurations for a serial single process, not a speedup demonstration.

Post-repair qualification: all twelve rejection variants pass; the actual operator-based FIFO passes 1,043 cycles against Icarus and the independent queue. The minimal parameter-value guard was independently reviewed and accepted.
